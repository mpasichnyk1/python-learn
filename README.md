# Python з нуля: перші дві зустрічі 🐍

Цей репозиторій — маленька навчальна лабораторія. Тут **не потрібно знати програмування заздалегідь**.
Мета — не запам'ятати всі команди, а навчитися читати код, експериментувати й самостійно розв'язувати задачі.

## Перед першою зустріччю

1. Встанови **Python 3** і **Visual Studio Code** з розширенням **Python**.
2. Відкрий у VS Code папку клонованого репозиторію: **File → Open Folder**.
3. Відкрий термінал: **Terminal → New Terminal**.
4. Перевір встановлення:

   ```powershell
   python --version
   ```

   На Windows, якщо команда `python` не працює, спробуй `py --version` і надалі використовуй `py` замість `python`.

5. Запусти перший файл із **кореневої папки репозиторію**:

   ```powershell
   python lesson_01/00_first_program.py
   ```

   У деяких системах треба використовувати `python3` замість `python`.

> Усі приклади працюють на стандартному Python: нічого додатково встановлювати через `pip` не потрібно.

## Як вчитися з цими файлами

1. Спочатку **передбач**, що виведе програма.
2. Запусти її та порівняй результат зі своїм прогнозом.
3. **Зміни один рядок**, запусти ще раз, поясни, що змінилося.
4. Виконуй завдання після позначок `СПРОБУЙ` і `TODO`.
5. Якщо бачиш помилку — прочитай **останній рядок** повідомлення й знайди відповідний номер рядка коду.

### Корисні відмінності

```python
print("Привіт")    # показати текст
name = "Оля"       # покласти значення в змінну
name == "Оля"      # запитати: чи дорівнюють значення?
# це коментар       # Python не виконує цей рядок
```

Текст з `input()` — **завжди рядок (`str`)**, навіть якщо ми ввели цифри.

## Домашнє завдання

Починай з папки відповідного заняття. Завдання — це **спеціально неповні, але синтаксично правильні** файли із `TODO`.
Необов'язково вирішувати бонусні ускладнення відразу.

Після виконання перевір файли запуском із термінала. Якщо користуєшся Git, перед комітом подивись `git status`.

## Як отримати оновлення з GitHub

У терміналі, стоячи в папці репозиторію:

```powershell
git status
git branch --show-current
git pull --ff-only origin main
```

**Важливо:** `git fetch` тільки завантажує інформацію про коміти. Він **не оновлює робочі файли**.
`git pull --ff-only origin main` отримує нові коміти й оновлює файли, якщо вдається зробити fast-forward. Якщо ваша основна гілка називається інакше, замініть `main`.
Якщо є незбережені локальні зміни чи Git повідомляє про конфлікт — **не застосовуй `reset --hard`**: спочатку збережи свою роботу й звернися до викладача.
