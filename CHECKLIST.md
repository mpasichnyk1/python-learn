# Самоперевірка після занять

## Після першого заняття

- [ ] Я вмію запустити `.py` з термінала VS Code.
- [ ] Я розумію, чим `print()` відрізняється від `input()`.
- [ ] Я можу пояснити різницю між `"12"` та `12`.
- [ ] Я знаю, що роблять `int()` та `float()`.
- [ ] Я можу написати `if / elif / else` без підглядання.
- [ ] Я розумію, чому в Python важливі відступи.
- [ ] Я змінив(ла) мінімум одну кінцівку інтерактивної історії.

## Після другого заняття

- [ ] Я розумію різницю між `for` та `while`.
- [ ] Я можу пояснити, що робить `range(1, 6)`.
- [ ] Я знаю, для чого потрібні функції та `return`.
- [ ] Я можу пояснити, чому в грі є `break` і `continue`.
- [ ] Я можу запустити й змінити власну маленьку гру.

**Важливо:** якщо щось не виходить — це сигнал, що тему треба спокійно повторити, а не переходити до наступної.
